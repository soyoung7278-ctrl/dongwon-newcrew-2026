04 · HRD-NET

미리 완료해 주세요.

앱 최초 실행 시 Bluetooth와 알림을 모두 ‘허용’해 주세요.
  1. 01
    고용24 개인회원 가입

    work24.go.kr → 회원가입 → 개인회원 가입

  2. 02
    로그인 후 실명인증

    상단 실명인증 → 주민등록번호와 성명 입력

  3. 03
    출결관리 앱 설치

    앱스토어 검색 → 설치 → 로그인

안내 이미지를 좌우로 넘겨 단계별로 확인해 주세요. →

04 · HRD-NET

회원가입과 앱 설치를
미리 완료해 주세요.

고용24에서 개인회원 가입과 실명인증을 완료하고, 휴대폰에 ‘고용노동부 HRD-Net 및 출결관리’ 앱을 설치해 주세요.

앱 최초 실행 시 Bluetooth와 알림을 모두 ‘허용’해 주세요.
  1. 01
    고용24 개인회원 가입

    work24.go.kr → 회원가입 → 개인회원 가입

  2. 02
    로그인 후 실명인증

    상단 실명인증 → 주민등록번호와 성명 입력

  3. 03
    출결관리 앱 설치

    앱스토어 검색 → 설치 → 로그인
